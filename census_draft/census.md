# Replication census of the Shiu et al. 2024 fly-brain model: first pass

Built 2026-10-10 from live fetches (GitHub REST search/code-search/commits APIs, raw.githubusercontent.com READMEs, Zenodo API). README text only; results files and docs folders were not read except where noted. Every quoted line is verbatim from the README fetched this session. `hand_checked = yes` means the parsed columns were read by hand in context; all other rows carry regex-extracted lines only and have not been read in context. Counts are lower bounds on the population and upper bounds on quality: see "Limits".

## Counts

- Non-fork repos whose README has a line with both `MN9` and a Hz value: **97** (plus 4 verbatim copies of another repo's README lines). 33 hand-checked.
- Non-fork repos whose README cites Shiu/the upstream repo or MN9 and that also hit a model-specific code search, but give no MN9 Hz line in the README: **175**.
- Non-fork repos whose README cites Shiu/MN9 only: **444**.
- Non-fork repos hit only by code search (model strings in code, README silent): 1010, in `census_code_hit_only.csv`.
- Forks (of any repo in the candidate set): 558, in `census_forks_of_any_repo.csv`.
- Direct forks of philshiu/Drosophila_brain_model: 75 listed by the API (upstream reports forks_count 80); 67 have 0 commits ahead of upstream main on their default branch, 8 are ahead (see below).

## Limits

- GitHub repo search returns at most 1,000 results per query; 9 of the README-scoped queries hit or approached that cap. Code search returned at most 1,000 file hits per query; 4 of 18 queries reported more than 1,000 hits (2 of those failed after page 1) and 2 more were within 10% of the cap.
- 1,044 of 1,384 repos found by code search had not been found by ~75 repo-search queries, so the two methods overlap little and the true population is larger than either.
- READMEs only. Known substantive projects (vichienFF/flybrain-connectome-benchmark, gianlucamazza/flymsg, Ibtisam-Mohammad/Fly.exe) keep their numbers in docs/results files and so show "not stated" here.
- Repo creation date is used for the month histogram; first-commit dates were fetched only for the MN9+Hz group.
- Not covered: private repos, GitLab/Codeberg/Hugging Face/Kaggle/Colab, X/Reddit/YouTube posts with no repo, Google Scholar, SSRN, OSF. Semantic Scholar returned HTTP 429 on every attempt. Zenodo search is metadata-only and one query timed out (504).
